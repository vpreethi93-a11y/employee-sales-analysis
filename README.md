# Employee Sales Analysis using PostgreSQL

## Project Overview

This project analyzes employee and sales data using PostgreSQL to understand salary patterns, employee performance, department performance, and sales trends.

## Tools Used

- PostgreSQL
- pgAdmin
- SQL

## Tables

- `employees` – employee details, department, salary, and hire date
- `sales` – sales transactions, products, dates, and sales amounts

## SQL Concepts

- Aggregate Functions
- GROUP BY
- CTEs
- Subqueries
- Window Functions
- ROW_NUMBER()
- LAG()
- PARTITION BY
- Date Analysis

## Analysis

- Above-average salaries
- Highest-paid employees
- Top employees by department
- Running sales totals
- Monthly sales
- Month-over-month sales growth
- Employee contribution to total sales
